# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
and is generated by [Changie](https://github.com/miniscruff/changie).


## v2.1.0 - 11-11-2026
### Added
* Crawl repositories on Forgejo and Gitea instances such as code.overheid.nl, so organisations registered with a code.overheid.nl URL are indexed in the OSS register.
### Fixed
* CI gebruikt de gedeelde workflows uit developer-overheid-nl/.github; test-images krijgen de tag test-<sha> en overschrijven de productie-image niet meer.
### Security
* Build the image in two stages and run on `debian:trixie-slim` with only `git` and CA certificates, upgraded on every build, so the curl and Brotli fixes for CVE-2026-111497 and CVE-2026-92392 are included and the Go toolchain no longer ships in the runtime image.

## v2.0.1 - 22-08-2026
### Fixed
* Reduce duplicate crawler logs, add structured don-crawler context through the shared don-register-common logger, classify expected repository outcomes at appropriate log levels, and update dependencies and CI actions to secure releases.

## v2.0.0 - 08-07-2026
### Changed
* Send archived repository status to the OSS register for GitHub, GitLab, and Bitbucket repositories.

## v1.1.1 - 19-05-2026
### Fixed
* Reduce crawler memory usage by running git operations through the native git CLI, using shallow clones based on ACTIVITY_DAYS, and cleaning up local clones after processing by default.

## v1.1.0 - 16-04-2026
### Added
* De crawler stuurt voortaan fork-informatie mee naar het register en gebruikt GitLab anoniem zonder tokenconfiguratie.

## v1.0.0 - 26-03-2026
### Changed
* GitHub Actions-workflows vastgepind op commit-SHA's en de image-builds voor test en productie-deploys gelijkgetrokken met de CI Docker-build.
