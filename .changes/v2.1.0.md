## v2.1.0 - 11-11-2026
### Added
* Crawl repositories on Forgejo and Gitea instances such as code.overheid.nl, so organisations registered with a code.overheid.nl URL are indexed in the OSS register.
### Fixed
* CI gebruikt de gedeelde workflows uit developer-overheid-nl/.github; test-images krijgen de tag test-<sha> en overschrijven de productie-image niet meer.
### Security
* Build the image in two stages and run on `debian:trixie-slim` with only `git` and CA certificates, upgraded on every build, so the curl and Brotli fixes for CVE-2026-111497 and CVE-2026-92392 are included and the Go toolchain no longer ships in the runtime image.
